| `tabs` | Parent container for language/option tabs. Accumulates TabItems. |

| `captioned-image` | Renders `src` + `caption` as `![caption](src)`. |
| `strip-tag` | JSX tags stripped, text content preserved. |
| `strip-block` | Entire component and all children removed. No content value. |
| `details` | `<summary>` becomes a heading; body expanded inline. |
