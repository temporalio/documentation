To load your API key from AWS Secrets Manager, set `TEMPORAL_EXT_AWS_SECRETS_MANAGER_API_KEY_ID` in your Lambda
environment or `api_key_id` under `profile.<profile>.ext.aws_secrets_manager` in TOML. Use the secret name or ARN.
If you set the secret ID in both places, the environment variable takes precedence.

You can also supply the API key directly with `TEMPORAL_API_KEY` or `api_key` in your TOML profile. The Worker fails at
startup if you configure both a direct API key and an API key secret ID, even when they come from different sources.

Grant the Lambda execution role [permission to read the secrets](/production-deployment/worker-deployments/serverless-workers/aws-lambda#use-aws-secrets-manager).
