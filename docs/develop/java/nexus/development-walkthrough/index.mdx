This walkthrough builds one Nexus Service from nothing to a complete API, adding one Nexus capability at each step.

A [Nexus Service](/evaluate/features/nexus) is a contract that one team publishes and other teams call across [Namespace](/namespaces) boundaries, without sharing code or a deployment.

## The walkthrough problem

A purchase request needs approval before it can proceed. One team owns that approval process, and
other teams across the company need to start an approval and find out how it went, without taking
on that team's code or running it themselves. That split is what makes this a Nexus problem: the
approval team publishes a Service, and everyone else calls it.

Approval is slow and human-driven, so the system has to survive a wait of minutes or weeks. While a request is pending, other systems might nudge the approver or attach information to the request. When a decision arrives, the requesting system needs the outcome.

The Service needs to:

- Start an approval and eventually return `APPROVED` or `DENIED`
- Accept a nudge that asks the approver again, and count how many have been sent
- Read an approval's progress without changing it
- Accept supporting information for a purchase, whether or not its approval exists yet
- Accept a decision and confirm it was recorded
- Send a notification when the decision is final

Each of those needs a different Nexus capability, introduced one step at a time.

## One contract, every language

**This walkthrough builds the Service in Java.** [NexGen](/nexus/nexgen) generates code from the same contract in Go, Python, and TypeScript, and the reasoning at each step is the same in all of them.

The Java sample is [nexuswalkthrough](https://github.com/temporalio/samples-java/tree/main/core/src/main/java/io/temporal/samples/nexuswalkthrough).

**Any caller can call any handler, because the contract is the only thing the two sides share.** A Go caller can drive a Python handler, and a TypeScript caller can drive the Java handler built here. [Step 6](/develop/java/nexus/development-walkthrough/call-the-service) builds the Java caller.

## Before you start

### 1. Clone the sample project {/* #clone-the-sample-project */}

This walkthrough runs inside a clone of the [samples-java](https://github.com/temporalio/samples-java)
repository. Every command and file path is relative to the repository root.

<RunThis>

```bash title="Run: clone the sample"
git clone https://github.com/temporalio/samples-java.git
cd samples-java
```

</RunThis>

The sample is the finished Service. Each step shows the code it introduces and then runs it.

### 2. Check your CLI version {/* #check-your-cli-version */}

This walkthrough needs [Temporal CLI](/cli) 1.9.1 or later and its development server. Each step
runs an Operation from the command line with `temporal nexus operation`, so check that your CLI has
those commands before you start. If `temporal nexus --help` doesn't list `operation`, upgrade.

The development server also needs two dynamic config values that are off by default.
[Step 4](/develop/java/nexus/development-walkthrough/implement-the-service#start-the-development-server)
sets them, and [Debugging and tips](/develop/java/nexus/development-walkthrough/debugging-and-tips)
shows what each one fails with when it's missing.

### 3. Run each Operation as you build it {/* #run-each-operation-as-you-build-it */}

[Step 4](/develop/java/nexus/development-walkthrough/implement-the-service)
starts the development server, and [step 5](/develop/java/nexus/development-walkthrough/publish-in-nexus)
makes the Service reachable. From then on, each step that adds an Operation ends by running it, so
you see a result before moving on. Those runs use `temporal nexus operation`, which starts a
[Standalone Nexus Operation](/standalone-nexus-operation): the CLI is the caller, so you need no
caller Workflow or caller Worker until [step 6](/develop/java/nexus/development-walkthrough/call-the-service).

New to Nexus? Read [Nexus Services](/nexus/services) and [Nexus Operations](/nexus/operations), or work through the shorter [Java Nexus quickstart](/develop/java/nexus/quickstart).
