Every Temporal Cloud plan includes support, and the plan you choose sets the response times, the channels you can reach Temporal through, and the depth of technical guidance you receive.
Coverage ranges from break/fix support and general guidance to code reviews, pre-production optimization, and operational readiness.

:::note

This page applies to Temporal Cloud customers only.

:::

## Temporal Cloud support guarantees {/* #guarantees */}

Temporal Cloud customers get break/fix support with an agreed set of SLAs for prioritized issues, entered, tracked, and closed through a ticketing system.
Depending on your plan, you can also reach support through a dedicated Slack channel, the community forums, and the knowledge base.

**Priority definitions**

- **P0 - Critical** (Production impacted)
  - The Temporal Cloud service is unavailable or degraded with a significant impact.
- **P1 - High** (Production issue)
  - An issue related to production workloads running on the Temporal Cloud service, or a significant project is blocked.
- **P2 - Normal** (General issues)
  - General Temporal Cloud service or other issues where there is no production impact, or a workaround exists to mitigate the impact.
- **P3 - Low** (General guidance)
  - Questions or an issue with the Temporal Cloud service that is not impacting system availability or functionality.

:::note On Page Service

P0: 24×7 (On Page Service) is offered for Enterprise and Mission Critical accounts.

:::

For the cost of each support level, see the [pricing page](/cloud/pricing).

## Ticketing

Temporal Cloud customers file tickets in the Temporal Support Portal.
For questions outside a ticket, use the [community Slack](https://temporalio.slack.com) and the [community Discourse forum](https://community.temporal.io/).

:::info

The Temporal Support Portal is for Cloud customers only, and all Cloud customers pay for support as part of their plan.
Other Temporal users have full community access except for the `#support-cloud` channel.

:::

### Access Temporal Support

1. Go to [support.temporal.io](https://support.temporal.io/).
2. If prompted, log in to Temporal Cloud with the method you normally use, such as Google, Microsoft, or email and password.
3. View open and closed tickets for your Temporal account, or submit a new one.

To request assistance from Temporal Support, see [Create a ticket](#support-ticket).

### Create a ticket {/* #support-ticket */}

:::info

This procedure applies only to Temporal Cloud customers whose contracts include paid support.
Without paid support, post your request in the [Temporal Community Forum](https://community.temporal.io) or the `#support-cloud` channel of the [Temporal workspace](https://t.mp/slack) in Slack.

:::

To create a ticket in the Temporal Support Portal:

1. Go to [support.temporal.io](https://support.temporal.io/).
2. If prompted, log in to Temporal Cloud using the same method you normally use (for example, Google, Microsoft, email-password, or other methods).
3. Click the **Create Ticket** button in the top right corner.
4. On the **Submit a ticket** page, enter the details of your request into the form. **Name**, **Subject**, and **Description** are required.
5. At the bottom of the form, choose **Submit**.
